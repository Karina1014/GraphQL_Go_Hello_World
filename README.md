# 🌐✨ GraphQL Hello World App
## 📖 About the Project
This project is a lightweight Go application designed to showcase the power of GraphQL! 🚀
It implements a basic server that can handle queries and send back structured responses. 📡

## 🚀 Getting Started
**🛠️ Prerequisites**
Before diving in, ensure that Go is installed on your machine. 🛤️
You can verify your installation by running:
```bash
go version
 ```
✅ Required Version: go1.23.2 or later.

## 📥 Installation
1️⃣ : Clone the repository
   ```sh
   git clone https://github.com/Karina1014/GraphQL_Go_Hello_World.git
  ```
2️⃣ : Initialize the module:
   ```sh
   go mod init main/architectural-styles/GraphQL
  ```
3️⃣ : Install necessary dependencies:
   ```sh
   go get github.com/graphql-go/handler
   go get github.com/graphql-go/graphql
  ```
## ⚙️ Running the Server
1️⃣: Launch the Server
Start the server by running the following command:
```sh
go run main.go
```
2️⃣: Open the GraphiQL Interface
Head to the following URL in your browser to open the interactive GraphiQL interface:
```sh
http://localhost:80
```
3️⃣: Test the GraphQL API
You can run a query like this to test the API:
```sh
{
  hello
}
```
